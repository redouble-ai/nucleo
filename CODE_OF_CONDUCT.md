# Code of conduct

Nucleo's issue tracker and pull requests are working conversations between engineers.

Be direct about the code and courteous to the person. Disagree with a design in terms of
what it does and what it costs. Assume the other side read what you wrote and meant what
they wrote. No personal attacks, no harassment, no discrimination, in any channel of this
project.

The same standard binds the maintainers: a closed pull request or a declined proposal is
told which category of [CONTRIBUTING.md](CONTRIBUTING.md) it fell into, and a question is
answered as a question.

Reports of behaviour that breaks this go to oss@redouble.ai and are read by a person.
Content that breaks it is removed, and an account that persists is blocked.
