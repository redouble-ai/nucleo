What to expect

An agent that calls Tools and admits Skills on its own, drawn live as it runs.

What to expect
  • GOODTwo or three turns:

    2. "briefly" admits the concise-answers Skill
    3. a one-line answer
  • TRYDrop "briefly" for a long answer with no Skill.
  • TRYRun at MICRO to watch a small model skip the Tool.

4 Read a directory

Read a folder into an index, all under a spend cap:

  • code and text layers for free
  • scans by a vision model
What to expect
  • GOODOn the shipped corpus, about 26 of 30 files in seconds for a few cents.
  • GOODThe scans are read by the vision tier.
  • TRYBudget 0.01:
    • model-tier rows are REFUSED before any money moves
    • code-tier rows still read
The folder is the one the demo ships, . To read a different folder, change DemoCorpus in nucleo-demo-engine.

5 Search what was read

Search the index by meaning. Run step 4 first.

What to expect
  • GOODThe headset-creak documents on top, although none says "helmet" or "squeak".
  • GOODThe top hit is the scanned letter.

6 Find the current prices

What does each product cost right now, from the documents step 4 read:

  1. a SMALL model extracts
  2. a MEDIUM model groups
  3. plain Java decides
What to expect
  • GOODAbout a minute and a third of a dollar for a dozen products.
  • GOODEvery price with the sentence it came from.
  • TRYMove the day back a month to see a rise turn into a scheduled price.

7 Benchmark the agent

Run step 3's query on every model you can call; a blind judge scores each against the strongest.

What to expect
  • GOODA minute or two and some tens of cents, then a table:
    • the judge's column tells the models that used the Tool from the ones that guessed
    • the cost column spreads tenfold

    3. split it
    4. pick the statement that decides a price change
  • BADA refusal naming a missing decision model: connect one in step 1.
